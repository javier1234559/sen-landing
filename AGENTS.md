# Agent entry point

When building this Astro app, read and follow [`docs/CONVENTION.md`](./docs/CONVENTION.md), [`docs/BRAND.md`](./docs/BRAND.md), and [`docs/NOTION-SYNC.md`](./docs/NOTION-SYNC.md) when changing content ingestion or CMS behavior.

Keep route files focused on route composition. Put reusable UI in `src/components`, page-level feature UI in `src/components/feature`, and shared shell components in `src/components/layout`.
